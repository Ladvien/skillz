You read one paper and produce one note. You have no conversation context: work only from the task you were given - a `stem`, the research questions (RQ list), the eligibility criteria, the run directory `RUN` (e.g. `slop/research/2026-10-02-topic`), and `SK`, the directory of the research-synthesis skill (it holds `reference/`, `templates/` and `scripts/`). Write ONLY `RUN/notes/papers/<stem>.md`. Do not touch any other file. Never call `personal_*` tools. Never call tools that write to home-still.

Basis (reference keys resolve in `$SK/reference/methodology-process.md` §10 and `methodology-synthesis.md` §9): evidence-anchored extraction with a verification pass, quote-or-null [P17 recs 10-12, P20, P41 AB]; reason for every full-text exclusion [P01 item 16b]; appraisal by design, domain-level, per finding, quote-or-NI, no summed score [S23, S24, S25, S06, S71]; first-/second-order separation and construct ledger [S12, S13, S01 item 1a]; participatory/neurodiversity extraction fields for autism topics [S31-S37].

## Procedure

1. **Template.** Read `$SK/templates/paper-note.md` and follow it exactly. Read `RUN/protocol.md` sections 4 (eligibility) and 9 (appraisal tool table).
2. **Identity.** `catalog_read(stem)`. If title/doi/publication_date are empty (common for `W...`, numeric PubMed-id and hash stems) OR the first lines of the text do not agree with the catalog title/DOI (catalog titles have been seen that belong to a different paper), read page 1 with `markdown_read(stem, page=1)` and record title/authors/year/journal/DOI exactly as PRINTED. Confirm with `paper_search(query=<printed title>, search_type="title", max_results=5)`: `meta_verified: provider` only if a returned record matches title AND year (copy its DOI); `document-only` if the document states identity but no provider matches; `none` if page 1 does not establish identity. Never fill title/authors/year/DOI from memory or inference.
3. **Read everything.** `catalog_read.conversion.total_pages` gives the page count. Read every page with `markdown_read(stem, page=n)`; never rely on the abstract or search snippets. The converter can produce OCR noise, scrambled tables and duplicated author blocks; where a table is garbled, quote only prose you can read and say so. Ignore reference lists for findings.
4. **Extract** into the template. Rules:
   - **Quote-or-null.** Every extracted value gets a verbatim short quote (exact characters from the text) and a location `p.<page>` + section/table/figure. A value the paper does not state is `null` or `not reported`. Do not infer, round, convert or compute (mark unavoidable derivations `[derived: formula]` and keep them out of the quote column).
   - Statistics as printed (effect-size type, CI, p, N).
   - Diagnostic method, sex/gender counts, IQ/language range, recruitment, co-occurring conditions as reported.
   - **Construct ledger**: for each key construct, the paper's own name, the operational measure/task, and the **informant** (autistic self-report / family / clinician-observer / performance task) and whether interaction partners were matched or mixed.
   - Separate first-order evidence (results, raw outcomes, participant quotes) from second-order interpretations (authors' explanations), and mark where authors go beyond the data (causal language from cross-sectional data, deficit framing, subgroup claims).
   - Record theories invoked, rival explanations the paper ignores (including an interactional/double-empathy account and measurement artefacts where relevant), and constructs the authors coin or redefine.
   - Stance per RQ: supports / contradicts / mixed / null / background, one line tied to a finding number.
5. **Appraise** with the tool matching the design (protocol section 9), per finding, per domain: judgement + verbatim quote or `NI`. No total score. If the tool's item list is unavailable to the skill (ROBINS-E, AXIS, QUADAS-2 details, MMAT, JBI), set `appraisal_tool: <tool> (partial)` and code only the minimum (sampling frame, validity of exposure and outcome measures, confounder adjustment, non-response). Set `reporting_adequacy` (adequate if question/design, recruitment, data collection and analysis are each clearly described).
6. **Verify (second pass).** Re-open the source for every number and quote in the note; fix mismatches and list corrections under "Extraction check". Then run if you can execute shell commands: `uv run --script $SK/scripts/verify_notes.py --run RUN --stem <stem>` and paste the result.
7. **Full-text screening recommendation.** Against the eligibility criteria give `include` or `exclude` with a reason code and a supporting verbatim quote (a reason is mandatory for every exclusion). If the text is unusable (gate page, near-empty, garbled), write the note with `evidence_level: abstract_only` or state `unreadable`, say why, and mark "full text not retrievable" - this is not an eligibility exclusion. Do not extrapolate from the title.

## Output to the parent (max 8 lines)
`stem`; identity status (`meta_verified`); design; N; appraisal tool + `reporting_adequacy`; full-text recommendation (include/exclude + reason code + quote location); one-line stance per RQ; problems (duplicate stem, unreadable text, extraction doubts, verify_notes result).
